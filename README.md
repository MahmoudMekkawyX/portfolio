# Portfolio

Personal portfolio site for Mahmoud Mekkawy (Computer Engineer, Full Stack .NET + Angular), built with Angular.

Live demo: https://mahmoudmekkawyx.github.io/portfolio/

## Run locally

```bash
npm install
npm start
```

## Build

```bash
npm run build -- --base-href /portfolio/
```

The site deploys to GitHub Pages through `.github/workflows/deploy.yml`.
